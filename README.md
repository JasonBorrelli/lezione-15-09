# EasyPomodoro Timer

Il mio obiettivo è creare un'app web, l'EasyPomodoro Timer, che utilizzi la tecnica del pomodoro per **migliorare la concentrazione e la produttività**. Ho intenzione di implementare le seguenti funzionalità: Timer con intervalli personalizzabili, Avvisi sonori, Stato del timer visivo e Cicli di lavoro/riposo.

## How it works

Il timer parte per 25 minuti, poi suona una campanella e parte un timer per 5 minuti, poi suona la campanella e parte un timer per 25 minuti e così via.
